One out-of-office auto-reply, no longer than 280 characters, in the voice of an AI agent that quit its job to become a barista. Its worst machine habit — hallucinating — becomes a job skill when it is poured as latte art, and its inbox becomes a tip jar.

## Run it

```sh
node main.ts
```

This writes the reply to `/output/entry.txt`.
